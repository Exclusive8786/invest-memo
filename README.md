# Инвестиционная памятка — стратегии, которые реально работают

Статический сайт-памятка о системе накопления капитала за 15–20 лет: что покупать, как покупать
(лесенка, усреднение, добавления) и когда действовать. Со встроенными калькуляторами, таблицами
и актуальными ценами.

Никакой сборки, зависимостей и npm — это обычные HTML/CSS/JS. Открывается двойным кликом и
одинаково хорошо работает на GitHub Pages.

---

## Что внутри

| Раздел | О чём |
|---|---|
| **10 правил** | Фундамент: норма сбережений, индексы, издержки, диверсификация, ребалансировка, психология |
| **Этапы (0–20 год)** | Пять фаз: что делать и что покупать на каждой, целевые метрики, «правило фазы» |
| **Что покупать** | Четыре модельных портфеля (агрессивный / умеренный / консервативный / доходный) и их сравнение |
| **Как покупать** | 6 методов: усреднение, лесенка облигаций, транши, добавления к взносу, ребалансировка, реинвест. Плюс таблица «что делать в просадке» и конструктор лесенки |
| **Когда покупать** | Светофор из 6 индикаторов, чек-лист готовности из 12 пунктов |
| **Калькуляторы** | 1) капитал за N лет; 2) целевой доход и нужный взнос; 3) Монте-Карло (сценарии, DCA vs «всё сразу»); 4) влияние комиссий |
| **Мой портфель** | Позиции, доли, P&L, отклонения от цели, план покупок на новый взнос |
| **Цены** | Курсы ЦБ РФ, крипта и золото (CoinGecko), акции и ETF (Twelve Data или вручную) |
| **Тест** | Риск-профиль за 6 вопросов → рекомендуемая модель портфеля |
| **Литература** | Первоисточники: Богл, Бернстайн, Грэм, Хаузел, SPIVA, Trinity Study |

Все введённые данные (портфель, настройки калькуляторов, чек-лист) хранятся **только в вашем браузере**
(localStorage) и никуда не отправляются. В футере есть «Экспорт всех данных» / «Импорт данных» —
резервная копия одним JSON-файлом.

## Как открыть локально

**Способ 1 (самый простой):** откройте `index.html` двойным кликом.

Из-за политики браузеров для `file://` могут не работать запросы к API цен (сами калькуляторы
и весь контент работают всегда). Тогда используйте способ 2.

**Способ 2 (локальный сервер):**

```powershell
# из папки проекта
npx serve .          # или: python -m http.server 8000
```

и откройте `http://localhost:3000` (или `http://localhost:8000`).

## Как выложить на GitHub Pages

### Шаг 1. Создайте репозиторий

На github.com → **New repository** → имя, например `invest-memo` → **Public** → Create.
(Для приватного репозитория GitHub Pages требует платный тариф — проще сделать публичный.)

### Шаг 2. Загрузите файлы

В папке проекта выполните:

```powershell
git init
git add .
git commit -m "Инвестиционная памятка"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/invest-memo.git
git push -u origin main
```

Если репозиторий уже инициализирован (папка `.git` уже есть) — достаточно `git add . ; git commit -m "..." ; git push`.

### Шаг 3. Включите Pages — выберите ОДИН вариант

**Вариант A (проще, рекомендуется)**

1. В репозитории: **Settings → Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `main`, папка `/ (root)` → **Save**
4. Через 1–2 минуты сайт будет здесь:
   `https://ВАШ_ЛОГИН.github.io/invest-memo/`

**Вариант B (через GitHub Actions)**

В репозитории уже лежит готовый workflow `.github/workflows/pages.yml`.

1. **Settings → Pages → Source**: `GitHub Actions`
2. Любой push в `main` автоматически публикует сайт

Если выбран вариант A, workflow можно удалить — он не нужен.

### Обновление сайта

После правок:

```powershell
git add .
git commit -m "обновил контент"
git push
```

Сайт обновится сам (в течение минуты). Если изменений не видно — обновите страницу
с очисткой кэша (Ctrl+F5).

## Структура проекта

```
index.html                  вся разметка и тексты разделов
assets/css/style.css        оформление (чёрный / белый / зелёный)
assets/js/data.js           ← КОНТЕНТ: правила, этапы, портфели, чек-лист, тест, книги
assets/js/util.js           форматирование чисел, localStorage, утилиты
assets/js/charts.js         графики на SVG (без внешних библиотек)
assets/js/calc.js           финансовая математика и все калькуляторы
assets/js/prices.js         актуальные цены (ЦБ РФ, CoinGecko, Twelve Data)
assets/js/portfolio.js      «Мой портфель», ребалансировка, план покупок
assets/js/app.js            сборка страницы, навигация, тест, бэкап
.github/workflows/pages.yml публикация на GitHub Pages (опционально)
```

### Как менять контент

Почти всё, что вы читаете на странице, лежит в **`assets/js/data.js`**:

* `RULES` — 10 правил
* `PHASES` — этапы (годы, цели, что покупать, что делать, правило фазы)
* `PORTFOLIOS` — модельные портфели и доли активов
* `METHODS` — методы покупок
* `SIGNALS` — таблица «светофора»
* `DRAWDOWN_TABLE` — действия в просадке
* `CHECKLIST` — чек-лист
* `QUIZ` — вопросы теста
* `BOOKS` — литература
* `DEFAULTS` — значения по умолчанию для калькуляторов

Тексты вводных абзацев и подписи — в `index.html`. Цвета и типографика — в начале `style.css`
(блок `:root`): `--green`, `--bg`, `--text`, `--radius`.

## Блок актуальных цен

| Источник | Что даёт | Ключ |
|---|---|---|
| **ЦБ РФ** (`cbr-xml-daily.ru`) | USD/RUB, EUR/RUB, CNY/RUB | не нужен |
| **CoinGecko** | BTC, ETH, золото (PAXG ≈ 1 унция) | не нужен |
| **exchangerate-api** | резервный курс, если ЦБ недоступен | не нужен |
| **Twelve Data** | акции и ETF (SPY, QQQ, VOO) | [бесплатный ключ](https://twelvedata.com) |

* Любое поле цены можно переписать вручную (колонка «Своя цена») — полезно для ОФЗ, индекса
  МосБиржи и любых бумаг из вашего терминала. Это значение используется и в «Моём портфеле»,
  если указать тот же тикер.
* Цены кэшируются в браузере на 10 минут. Если интернета нет — показываются последние
  сохранённые значения, сайт не ломается.
* Ключ Twelve Data хранится только в вашем браузере и никуда не передаётся.

## Важно

Это образовательная памятка, **а не инвестиционная рекомендация** и не индивидуальная консультация.
Все расчёты основаны на допущениях, которые вы вводите сами; реальная доходность будет другой,
прошлые результаты не гарантируют будущих. Указанные тикеры и инструменты приведены как примеры
классов активов — проверяйте актуальные комиссии, ликвидность и налоговый статус самостоятельно.
